# JanDorm Official Booking Website Concept

This folder contains the complete JanDorm bilingual booking-website prototype.

## Open the Website

Open `index.html` in a modern browser. All required pages, scripts, styles, and images use relative paths and are stored inside this folder.

## Project Structure

```text
JanDorm_Official_Booking_Website/
|-- index.html                 Homepage and product experience
|-- booking.html               Interactive booking flow
|-- styles.css                 Shared responsive design system
|-- app.js                     Homepage navigation, gallery, and interactions
|-- booking.js                 Calendar, room selection, add-ons, and confirmation
|-- favicon.svg                Browser icon
|-- og.png                     Social-preview image
|-- assets/
|   |-- jandorm-exterior.jpg

|   |-- window-pocket.png

|   `-- room-3d-placeholder.png
`-- README.md
```

## Included Experiences

- Responsive English and Japanese homepage
- Animated hero-image gallery
- Stay, Rooms, Bag Care, Workshop, and About sections
- Pocket Capsule and Window Pocket room concepts
- Bag Onsen backpack-care concept
- Instructor-led repair and customization workshop
- Room-preview placeholder
- Functional booking interface with month navigation
- Room, guest, date, and add-on selection
- Prototype reservation confirmation
- Mobile navigation and delayed mobile booking action
- Concept and affiliation disclaimer

## Important Disclaimer

JanDorm is an independent academic design concept inspired by JanSport. It is not an operating hotel, official JanSport service, or real booking platform. Prices, availability, dates, room details, service descriptions, and confirmations are illustrative prototype content. Bag Onsen refers only to backpack cleaning and care; it is not a bathing or hot-spring facility for guests.
